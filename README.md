# Beginner Web Dev Course


## Module 2: Click Counter


A simple interactive project to help you learn JavaScript basics, DOM manipulation, and event listeners.

## 🎯 Project Goal
Learn how to:
- Select and update HTML elements with JavaScript
- Use `addEventListener` to handle button clicks
- Display and update a counter value

## 📁 Project Structure

```markdown
click-counter/
├── index.html     # The main HTML file
└── script.js      # JavaScript logic for interactivity

```

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone git@github.com:andela-sjames/click-counter.git
cd click-counter
````

### 2. Open the Project

Use a code editor like [VS Code](https://code.visualstudio.com/) to view and edit the files.

### 3. Run the App

Just open `index.html` in any web browser. Click the button and watch the counter go up!

## 🧠 How It Works

* HTML provides the structure: a button and a counter
* JavaScript finds the button using `getElementById`
* Each time the button is clicked, a number is increased and displayed

## 🌐 Deployment

To publish your click counter online:

1. Push to GitHub
2. Go to your repo → Settings → Pages
3. Choose the `main` branch and `/root` folder
4. Click Save and your project will be live!
